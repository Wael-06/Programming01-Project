# Bank Management System (C)

*A CSE 221 course project implementing a command-line bank management system in C.*

---

## Features

- Account CRUD, search, and sorting.
- Deposits, withdrawals, and transfers.
- File-based data persistence and transaction history.
- Input validation and daily transaction limits.

---

## Build & Run

**Requirements:** GCC and Make

```bash
make
./bank_system
```
