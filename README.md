🏦 Bank Management System
Course: Programming (1) - CSE126, Alexandria University, Faculty of Engineering, Computer & Communication Program

✨ Project Objective
Our goal was to build a complete and robust Bank Management System in C using a console-based interface. The focus was on creating a well-structured, user-friendly system that manages bank accounts securely and reliably.

The system supports essential banking operations, user authentication via a login system, and persistent storage of account and transaction data.

🛠️ Key Features

🔑 User Login

Secure login using credentials stored in a file before accessing the system menu.

📂 Account Management

Load: Initialize system with account data from a file.

Add Account: Create new accounts with automatic status and creation date.

Modify Account: Update name, mobile number, or email.

Delete Account: Remove accounts with zero balance.

Change Status: Toggle account status between 'active' and 'inactive'.

Bulk Delete (Bonus): Delete multiple accounts based on age or inactivity.

💰 Transactions

Deposit / Withdraw / Transfer with rules for transaction limits and active account checks.

Transaction History: View the last 5 transactions for each account.

🗃️ Reporting & Output

Query / Search: Standard and advanced search by account number or name keyword.

Print & Sort: Display all accounts sortable by Name, Balance, or Date Opened.

Save: Store all updates back to the account file.
