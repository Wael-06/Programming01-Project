Course: Programming (1) - CSE126, Alexandria University, Faculty of Engineering, Computer & Communication Program

---

✨ Project Overview
Our team developed a **comprehensive and robust Bank Management System** in C, designed to operate in a console environment. This project goes beyond academic requirements, showcasing our ability to create a **well-structured, secure, and user-friendly system** capable of handling real-world banking operations with **accuracy and reliability**.

The system ensures **data integrity**, **secure user authentication**, and **persistent storage** of all account and transaction data, making it a complete and professional solution.

---

🛠️ Key Features

🔑 User Login
- **Secure login system** using credentials stored in a file, ensuring authorized access to the system.

📂 Account Management
- **Load Accounts:** Initialize the system from a data file.  
- **Add Account:** Create new accounts with **automatic active status** and **current date**.  
- **Modify Account:** Update **account holder’s name, mobile number, and email**.  
- **Delete Account:** Remove accounts with **zero balance only**.  
- **Change Status:** Toggle account status between **active** and **inactive**.  
- **Bulk Delete (Bonus):** Remove multiple accounts based on **age or inactivity**, demonstrating advanced data management skills.

💰 Transactions
- **Deposit / Withdraw / Transfer** with rules for **transaction limits** and **active account verification**.  
- **Transaction History:** Display the **last 5 transactions** per account for transparency.

🗃️ Reporting & Output
- **Query / Search:** Standard search by **account number** or advanced search by **name keyword**.  
- **Print & Sort:** Display all accounts **sortable by Name, Balance, or Date Opened**.  
- **Save:** Persist all modifications back to the system’s data file.
